Trading Data Platform Overview

This page describes where trading and reference data lives and how it is refreshed.

Trade storage

All executed trades, both house and Authorised Participant (AP) flow, are stored in the Trading Data Warehouse, table dwh.trades. The table is loaded by an end-of-day batch at 20:00 UTC; intraday trades are published to the Kafka topic trades.executed.v1 within two seconds of execution.

Participants

Authorised Participants are mastered in dwh.participants. Participant type is one of AP, HOUSE, CLIENT.

Reference data

Security reference data, including GICS sector and industry classification, lives in ref.security_master and is owned by the Data Governance team. Classification changes are applied monthly.

Existing consumers

  • The Trade Blotter API exposes trade-level records and is used by the operations desk.
  • There is no aggregated net-flow view today; analysts compute it in spreadsheets.
